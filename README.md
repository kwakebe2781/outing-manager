# GoPlan｜おでかけプラン

GoPlanは、行きたい場所を集めて、おでかけの予定を整理するWebアプリです。スマートフォンとPCで使えるように設計しています。

## 現在の開発状態

- 開発用ブランチ：`goplan-complete-dev`
- 開発PR：[#3 GoPlan completion build](https://github.com/kwakebe2781/outing-manager/pull/3)
- PRはDraft（下書き）です。**まだ公開版の `main` には反映していません。**
- GitHub Actionsでは、フロントエンド検査とWorker検査の両方が成功しています。
- Cloudflare Worker / D1はコードを用意した段階で、実際のCloudflareアカウントにはまだデプロイしていません。Googleログイン、PLANI AI、クラウド同期、通知は、本番設定と実機確認が終わるまで「本番で動作確認済み」とは扱いません。

## アプリに含まれる機能

### 画面・管理
- 公式GoPlanアイコンとPLANIロゴ
- NATURAL、TIGERS CLASSIC、TIGERS NIGHT、VINTAGE TIGERSの4テーマ
- ライト／ダーク／システム表示、アクセントカラー、端末別テーマ上書き
- ホーム、行きたいリスト、予定、カレンダー
- 行きたい場所のジャンル・行きたい度・エリア・予算フィルターと並べ替え
- 予定の過去／これからフィルターと並べ替え
- プロフィール名・写真
- 画面別壁紙。壁紙は端末ごとが基本で、同期は任意
- 写真ファイルの追加、写真の圧縮、最大3枚の保存
- PLANIによるWikimedia Commons画像候補検索。取り込む画像は出典ページとライセンス情報を保存
- 場所やプランからGoogleマップを開くリンク。プランの経由地ルートもGoogleマップで表示

### PLANI / GoPlan AI
- AIチャット、場所検索、プラン提案の画面
- 検索結果の出典表示。出典URLはResponses APIが実際に返した引用と照合
- 候補の確認後に行きたい場所へ追加
- 行程を選択してから予定へ登録
- 会話履歴の保存・再開・名前変更・削除
- AIプランの保存・編集・複製・削除・予定登録
- 本人が承認したAIメモリーの保存・編集・削除・参照ON／OFF
- AI利用回数の表示

### 同期・バックアップ
- Google OAuthでアカウントを確認する構成
- Cloudflare D1にGoogleアカウントごとのデータを保存するWorker
- 同時編集時は古い更新を自動上書きせず、競合として検出
- クラウドバックアップ、復元前保護、最大5件の保持
- アカウントデータ削除前に保護バックアップを作成
- IndexedDBを使った端末内バックアップと、アプリシェルのオフラインキャッシュ

### 通知
- 予定リマインド
- 保存した場所の情報変更・イベントの監視
- アプリ内通知履歴と出典リンク
- Web Pushの登録、テスト送信、端末ごとの解除
- 初期時間帯は日本時間の毎日6:00〜22:00

## 重要：本番接続に必要な設定

バックエンドのコードは `worker/` にあります。設定方法は [worker/README.md](worker/README.md) を確認してください。

本番利用には、Cloudflareアカウント、D1データベース、Google OAuthの公開クライアントID、OpenAI API、Web Push用VAPIDキーが必要です。APIキーや秘密鍵はHTMLやGitHubに書き込まず、WorkerのSecretとして設定します。API利用料がかかるサービスの作成・課金設定は、保護者と確認してから行ってください。

`worker/wrangler.toml` に残っている `REPLACE_WITH_...` を実際の値に設定し、D1マイグレーションを適用してからWorkerをデプロイする必要があります。今のリポジトリには実際のキーやデータベースIDは保存していません。

## まだ実機確認が必要なこと

- 実際のGoogleアカウントを使ったOAuthログイン
- Cloudflare D1とWorkerへのデプロイ、データ読み書き、競合・復元
- OpenAI APIの実接続、Web検索の出典、使用量
- iPhone／AndroidでのPWAインストール、Push通知、オフライン表示
- 複数端末での同期と写真容量の長期運用

Googleマップ機能は外部のGoogleマップを開く方式です。アプリ内地図、アプリ内の経路描画、移動時間の自動計算はまだ含まれていません。オフライン時は端末に保存済みの情報を表示できますが、AI検索・クラウド同期・最新情報確認には通信が必要です。
